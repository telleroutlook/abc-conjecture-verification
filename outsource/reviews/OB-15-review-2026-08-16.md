in 126 R<c triples (c ≤ 200).**

## Structural theorem confirmed (new, proved here)

**Theorem (c prime ⟹ R ≥ c).** If c is prime, then rad(c) = c, so
R = rad(a)·rad(b)·c ≥ c. Hence R < c is impossible when c is prime.

*Corollary:* R < c implies c is composite. Since R < c also implies c is
non-squarefree (proved in Observation 1), R < c implies c is composite and
non-squarefree (has a prime power factor p^e with e ≥ 2).

## Empirical observation: ω* ≤ 4 for R < c — DISPROVED

A search over all coprime triples with c ≤ 10000 and R < c finds no case with ω* ≥ 5.
However, **this bound is false for large c**. Explicit counterexample (found post-review):

- Triple: (1, 67092480, 67092481) with c = 8191² (Mersenne prime p=8191=2¹³−1)
- b = p²−1 = 2¹⁴·3²·5·7·13; ω*=6 (primes 2,3,5,7,13,8191)
- R = 22,361,430 < c = 67,092,481 ✓

**OB-15 still holds for this triple:** within-group construction in Pb (v_2=14 ≠ v_3=2)
gives φ_2=1, φ_3=−7, W=−6≠0, ‖φ‖=21. Then 21 ≤ 14·R^{1/5} ≈ 413. ✓

**Implication:** The proof of OB-15 cannot rely on ω*≤4. The within-group construction
is essential for large-ω* cases, and the proof strategy must accommodate all ω*.

## Gap 1 — KEY inequality not proved [MAJOR]

**Finding:** OB-15 states "OB-15 reduces to showing med(m_a,m_b,m_c) ≤ R^{1/(ω*-1)}
when R < c (KEY)." This KEY inequality is **not proved in the skeleton**.

**Blocking case:** (1,48,49): ω*=3, R=42, c=49, med=7. KEY: 7 ≤ √42 ≈ 6.48? **FALSE.**
Yet OB-15 holds (nd=7 ≤ 4·6.48≈25.9) because a cross-group construction gives nd=7
directly — the path to OB-15 does NOT go through KEY for this triple.

**Implication:** KEY is sufficient for OB-15 but NOT necessary. The proof skeleton
must be restructured: instead of proving KEY universally, prove OB-15 directly for
each structural case by exhibiting an explicit construction with norm ≤ v_max·R^{1/(ω*-1)}.

**Partial fix:** For the single-prime-c-group case with ω*=2 (one prime q in Pb,
one prime p in Pc): R = q·p, v_max = e (where c = p^e). nd ≤ v_max·p (cross-group).
Need v_max·p ≤ v_max·(qp)^{1/1} = v_max·qp, i.e., p ≤ qp, i.e., 1 ≤ q. Trivially
true. ω*=2 is closed unconditionally.

## Gap 2 — Same-valuation same-group case not addressed [MEDIUM]

**Finding:** Step 3 assumes within-group assistance is available when two primes in
the same group have unequal valuations. But when v_p = v_q for all pairs in a group
(including the squarefree subcase v_p = v_q = 1), no within-group non-degenerate
vector exists.

**Blocking case:** a = p₁p₂ (squarefree), b = q^e (prime power), c = a+b (non-squarefree
with R < c). Here Pa={p₁,p₂} has equal valuations (v_p₁=v_p₂=1), Pb={q} is a singleton,
Pc = single prime. Within-group in Pa is degenerate. Only cross-group constructions
available; the cross-group bound nd ≤ v_max·med needs KEY to connect to R^{1/(ω*-1)}.

**Fix required:** Show that for R < c triples with squarefree Pa (or Pb), the cross-group
bound nd ≤ v_max·med together with a direct R<c argument gives nd ≤ v_max·R^{1/(ω*-1)}.
This requires the case analysis to avoid KEY or to prove KEY for the specific sub-cases
where equal-valuation groups arise.
