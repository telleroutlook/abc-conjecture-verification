## 1. 首要逻辑审计：\(\varepsilon\) 是空参数

令

\[
R=\operatorname{rad}(abc).
\]

Claim OB-01 的原文是

\[
\forall\varepsilon>0\ \exists C_\varepsilon>0\ \forall(a,b,c),
\qquad h_F(E_{a,b,c})\le C_\varepsilon(1+\varepsilon)\log R.
\tag{1.1}
\]

由于 \(C_\varepsilon\) 没有任何规定的大小或渐近条件，外面的 \(1+\varepsilon\) 可完全吸收到常数中：

* (1.1) 推出固定界：取 \(\varepsilon=1\)，令 \(K=2C_1\)，则

  \[
  h_F(E_{a,b,c})\le K\log R
  \tag{1.2}
  \]

  对所有三元组成立。

* 反之，若存在可计算的固定 \(K\) 使 (1.2) 成立，定义

  \[
  C_\varepsilon=\frac{K}{1+\varepsilon}
  \]

  即得 (1.1)。

所以 Claim OB-01 **等价于固定系数的 \(O(\log R)\) 高度界**，并没有标准 \(abc\) 中“指数任意逼近 1”的内容。

送审稿 Note 中还有一个直接的指数丢失。由后文无条件下界

\[
h_F(E_{a,b,c})\ge \frac16\log c-C_3
\]

和 (1.1) 实际只能得到

\[
\log c\le 6C_\varepsilon(1+\varepsilon)\log R+6C_3,
\]

即

\[
c\le e^{6C_3}R^{\,6C_\varepsilon(1+\varepsilon)}.
\tag{1.3}
\]

稿件把指数 \(6C_\varepsilon(1+\varepsilon)\) 无理由地改成了 \(1+\varepsilon\)。因此“Claim OB-01 的证明将构成标准 \(abc\) 的证明”不成立。

不过，(1.3) 仍然极强：它是**有效固定幂弱 \(abc\)**，也就是质量

\[
q(a,b,c)=\frac{\log c}{\log R}
\]

有一个全局有效上界。这个较弱命题目前同样开放。

## 2. Step 1：最小判别式的完整闭合

### 2.1 精确命题

对任意互素正整数三元组 \(a+b=c\)，曲线

\[
E_{a,b,c}:y^2=x(x-a)(x+b)
\]

满足

\[
c_4=16(a^2+ab+b^2),\qquad
\Delta_W=16a^2b^2c^2.
\tag{2.1}
\]

而全局最小判别式**恰有二选一**：

\[
\boxed{
|\Delta_{\min}(E_{a,b,c})|
\in\left\{16(abc)^2,\ 2^{-8}(abc)^2\right\}.
}
\tag{2.2}
\]

这是 [Silverman, *The Arithmetic of Elliptic Curves*, 2nd ed. (2009), Lemma VIII.11.3(a)](https://www.math.ens.psl.eu/~obenoist/refs/Silverman.pdf) 的直接应用：在该引理中取 \(A=b\)、\(B=a\)、\(C=a+b=c\)。因此统一界可精确加强为

\[
\boxed{
2\log(abc)-8\log2
\le \log|\Delta_{\min}|
\le 2\log(abc)+4\log2.
}
\tag{2.3}
\]

原稿的 \(-14\log2\) 与 \(+8\log2\) 都安全但不最优。

### 2.2 为什么只有两个值

若用

\[
x=u^2x'+r,\qquad y=u^3y'+u^2sx'+t
\]

把给定整模型化为全局最小整模型，则 Silverman 引理中的两个 Bézout 恒等式给出 \(u^4\mid288\)。故 \(u\in\{1,2\}\)，而判别式按 \(u^{-12}\) 缩放：

\[
u=1\Rightarrow |\Delta_{\min}|=16(abc)^2,
\qquad
u=2\Rightarrow |\Delta_{\min}|=2^{-8}(abc)^2.
\]

这也纠正了“去掉 \(p^{12}\)-幂”式的过度简化：最小化由允许的 Weierstrass 变量变换控制，并非把判别式整数机械除以所有十二次幂。

### 2.3 两端常数都达到

上端由 \((a,b,c)=(1,1,2)\) 达到：

\[
y^2=x^3-x,\qquad |\Delta_{\min}|=64=16(1\cdot1\cdot2)^2.
\]

下端由 \((a,b,c)=(16,1,17)\) 达到。原模型作变换 \(x=4X,\ y=8Y+4X\)，得到

\[
Y^2+XY=X^3-4X^2-X,
\]

其判别式为

\[
17^2=2^{-8}(16\cdot1\cdot17)^2.
\]

唯一非零判别式赋值是 \(v_{17}=2<12\)，故该整模型已全局最小。因此 (2.3) 的两端常数都不能统一改善。

### 2.4 奇素数处的精确局部结论

若奇素数 \(p\mid abc\)，互素性保证 \(p\) 只整除 \(a,b,c\) 中一个。由 (2.1)：

\[
\begin{array}{c|c}
p\mid a & a^2+ab+b^2\equiv b^2\not\equiv0\pmod p\\
p\mid b & a^2+ab+b^2\equiv a^2\not\equiv0\pmod p\\
p\mid c & b\equiv-a\pmod p,\quad a^2+ab+b^2\equiv a^2\not\equiv0\pmod p.
\end{array}
\]

故 \(p\nmid c_4\) 而 \(p\mid\Delta\)，约化为乘法型，并且

\[
v_p(\Delta_{\min})=2v_p(abc).
\tag{2.4}
\]

这也是 [Silverman, Lemma VIII.11.3(b)](https://www.math.ens.psl.eu/~obenoist/refs/Silverman.pdf) 的原结论。原稿中“\(p^2\Vert abc\)”不对：有关赋值可以任意大；正确式是 (2.4)。

## 3. Step 2：Faltings 高度下界的完整闭合

### 3.1 必须先固定归一化

Faltings 高度有若干通行归一化，彼此相差固定加法常数。存在性命题 \(h_F=O(\log R)\) 不受影响，因为每个三元组都有 \(R\ge2\)；但具体数值核验必须先声明归一化。

采用 M. Ram Murty 与 Hector Pasten 的归一化。[Murty–Pasten, *Modular forms and effective Diophantine approximation*, J. Number Theory 133 (2013), Theorem 5.1](https://people.math.harvard.edu/~hpasten/preprints/modabcJNT.pdf) 给出

\[
12h_F(E)
=\log|\Delta_E|
-\log\bigl(|\Delta(\tau_E)|(\operatorname{Im}\tau_E)^6\bigr)
+12\log(2\pi).
\tag{3.1}
\]

同文 Lemma 5.3 对模形式项作统一上界，Theorem 5.4 得到

\[
12h_F(E)>\log|\Delta_E|+28.326.
\tag{3.2}
\]

结合 Step 1 与 \(abc\ge c\)：

\[
\begin{aligned}
12h_F(E_{a,b,c})
&>2\log(abc)-8\log2+28.326\\
&\ge2\log c-8\log2+28.326.
\end{aligned}
\]

所以

\[
\boxed{
h_F(E_{a,b,c})>
\frac16\log c+
\frac{28.326-8\log2}{12}
=\frac16\log c+1.8984018796\ldots
}
\tag{3.3}
\]

在其他标准归一化下，(3.3) 变为

\[
h_F(E_{a,b,c})\ge\frac16\log c-C_3
\]

而 \(C_3\) 仍是绝对常数。因此 Step 2 的目标结论成立。

### 3.2 原稿中必须删除或改写的两点

第一，送审稿归于 “Silverman, *Advanced Topics*, Chapter II, Theorem 1.1” 的实周期公式不是这里所需的准确引文；其写法还遗漏了归一化依赖。应以 (3.1)–(3.2) 代替。

第二，原稿声称 \(h(j(E))=h_F(E)+O(1)\) 且常数对所有椭圆曲线一致，这是错误的。精确比较含有 \(\log(1+h(j))\) 项及不稳定判别式项；参见 [Steffen Löbrich, *A Gap in the Spectrum of the Faltings Height*, JTNB 29 (2017), Proposition 3.1](https://www.numdam.org/item/JTNB_2017__29_1_289_0.pdf)。该文 Definition 2.3 与 Remark 2.1 也明确列出不同归一化的加法常数差异。

此外，“由高度下界可等价地把高度上界换成判别式上界”只能给一个方向：高度上界加 (3.2) 可推出判别式上界；判别式上界本身并不自动给出高度上界，还需控制阿基米德项或 \(j\)-高度。

## 4. Step 3：导子上界的完整闭合

由第 2.4 节，所有奇素数 \(p\mid abc\) 都是乘法约化，因此局部导子指数恰为 \(f_p=1\)。若奇素数 \(p\nmid abc\)，给定整模型的判别式是 \(p\)-单位，故为好约化。因而

\[
N_E=2^{f_2}\prod_{\substack{p\mid abc\\p\ {\rm odd}}}p.
\tag{4.1}
\]

在 \(p=2\) 处，标准局部导子公式给出 \(0\le f_2\le8\)。Silverman Proposition VIII.11.5 的证明在引用 Lemma VIII.11.3(b) 后正是把 (4.1) 写成奇数素因子的无平方乘积乘一个有界的 2 次幂。2、3 剩余特征下的局部表可见 [Barrios–Roy, *Local data of rational elliptic curves with nontrivial torsion*, Pacific J. Math. 318 (2022), §2 and Lemma 2.2](https://msp.org/pjm/2022/318-1/pjm-v318-n1-p01-s.pdf)。

因为 \(a,b,c\) 中恰有一个偶数，

\[
R=2\prod_{\substack{p\mid abc\\p\ {\rm odd}}}p.
\]

代入 (4.1)：

\[
\boxed{
N_E=2^{f_2-1}R,\qquad
\log N_E\le\log R+7\log2.
}
\tag{4.2}
\]

这比送审稿的 \(2\log R+6\log2\) 强一个主项因子。

但“坏约化素数恰为 \(p\mid abc\)”在 \(p=2\) 处并不总对。例如 \((16,1,17)\) 的上述最小整模型判别式为 \(17^2\)，故在 2 处好约化，尽管 \(2\mid abc\)。正确说法是：奇素数坏约化集合恰为奇素数 \(p\mid abc\)，而 2 处须单独处理。

## 5. Claim OB-01 的真实等价前沿

### 5.1 Claim 推出有效固定幂弱 \(abc\)

由第 1 节，Claim 等价于存在可计算固定 \(K\) 使

\[
h_F(E_{a,b,c})\le K\log R.
\]

与 (3.3) 合并便得

\[
c\le K_0R^{6K},
\tag{5.1}
\]

其中 \(K_0\) 可计算。因此 Claim 推出有界质量，但不推出标准 \(abc\) 的 \(1+\varepsilon\) 指数。

### 5.2 反向比较：固定幂弱 \(abc\) 足以给 Claim

Frey 曲线的 \(j\)-不变量为

\[
j(E_{a,b,c})
=\frac{256(a^2+ab+b^2)^3}{a^2b^2c^2}.
\tag{5.2}
\]

由于 \(a^2+ab+b^2<c^2\) 且 \(a,b<c\)，有理数 Weil 高度满足

\[
h(j(E_{a,b,c}))\le6\log c+8\log2.
\tag{5.3}
\]

Löbrich Proposition 3.1（源自 Silverman 的高度比较）给出

\[
h_F(E)\le\frac1{12}h(j(E))
+\frac1{12}\log|\gamma_E|+O(1),
\tag{5.4}
\]

其中 \(\gamma_E\) 是不稳定判别式。对本 Frey 族，所有奇素数处均半稳定，唯一可能的不稳定素数是 2。由 (2.2) 的最小化参数 \(u\in\{1,2\}\) 以及 \(v_2(c_4)=4\)，最小模型满足 \(v_2(c_{4,\min})\in\{0,4\}\)。按 \(\gamma_E\) 的定义，其 2-adic 指数至多 \(3v_2(c_{4,\min})\le12\)，所以该项统一有界。因此

\[
h_F(E_{a,b,c})\le\frac12\log c+O(1).
\tag{5.5}
\]

若存在有效固定幂界 \(c\le K_0R^A\)，则 (5.5) 给出

\[
h_F(E_{a,b,c})\le\frac A2\log R+O(1).
\]

又因 \(R\ge2\)，加法常数可吸收到 \(\log R\) 的系数，得到 Claim OB-01。故在有效常数层面，Claim 与本 Frey 族的**有效固定幂弱 \(abc\)** 等价。

还可把 \(c\) 版本与 \(abc\) 版本互换，因为

\[
c\le abc<c^3.
\]

Hector Pasten 把相应固定幂命题明确列为 Conjectures 1.1–1.2，并说明二者仍开放；见 [*Shimura curves and the abc conjecture*, J. Number Theory 254 (2024), §1.1](https://arxiv.org/html/1705.09251v4)，DOI [10.1016/j.jnt.2023.07.002](https://doi.org/10.1016/j.jnt.2023.07.002)。

### 5.3 无条件结果离目标多远

对任意 \(E/\mathbb Q\)，Murty–Pasten Theorem 7.1 给出

\[
h_F(E)<0.1N_E\log N_E+11,\qquad
\log|\Delta_E|<1.2N_E\log N_E+93.
\tag{5.6}
\]

由 (4.2)，这对 Frey 曲线至多给 \(O(R\log R)\)，不是 Claim 所需的 \(O(\log R)\)。

对一般 \(abc\) 三元组，目前最强的无条件全局形状仍是 Stewart–Yu 型

\[
\log c\le\kappa R^{1/3}(\log R)^3.
\tag{5.7}
\]

见 [C. L. Stewart–Kunrui Yu, *On the abc conjecture, II*, Duke Math. J. 108 (2001), Theorem 1](https://projecteuclid.org/journals/duke-mathematical-journal/volume-108/issue-1/On-the-abc-conjecture-II/10.1215/S0012-7094-01-10815-6.full)。Pasten 的 [2024 年 Inventiones 论文](https://arxiv.org/html/2312.03566v1) 在额外条件下改进若干次指数界，但其引言第 (1.7) 式仍把 (5.7) 列为任意三元组的最佳无条件界。它与固定幂 \(c\le K_0R^A\) 之间仍有本质距离。

因此 Step 4 不是已有定理中的常数优化问题，而是开放猜想本身。

## 6. Step 4 的具体错误与正确替代

送审稿称某个固定

\[
\log|\Delta_{\min}(E)|\le C_{\mathrm{Szp}}\log N_E+O(1)
\tag{6.1}
\]

是“Szpiro 猜想”，又把它直接说成标准 \(abc\) 的等价命题。这里必须区分：

1. 存在某个固定 \(C_{\mathrm{Szp}}\) 的 (6.1) 是**弱／固定幂 Szpiro**。
2. 指数 \(6+\eta\)（对每个 \(\eta>0\)）是通常的强 Szpiro 形式。
3. 与标准 \(abc\) 精确等价时还须说明使用的是哪一种修正 Szpiro 版本及指数换算。

在本 Frey 族上，(6.1) 与固定幂弱 \(abc\) 互相推出；但这不足以给标准 \(abc\)。[Silverman, Proposition VIII.11.5](https://www.math.ens.psl.eu/~obenoist/refs/Silverman.pdf) 也明确显示，朴素 \(6+\eta\) Szpiro 通过该基本 Frey 曲线论证只直接给 \(abc\) 指数 \(3/2\)，而不是 \(1+\eta\)。送审稿引用 Hindry–Silverman 的扭点论文却未给定理号，也未区分这些变体，不能支持其精确等价陈述。

代数换算也应改正。由 Steps 1、3 与 (6.1)：

\[
2\log c-O(1)
\le\log|\Delta_{\min}|
\le C_{\mathrm{Szp}}\log N_E+O(1)
\le C_{\mathrm{Szp}}\log R+O(1),
\]

故

\[
\log c\le\frac{C_{\mathrm{Szp}}}{2}\log R+O(1).
\tag{6.2}
\]

送审稿给出的 \(C_\varepsilon=C_{\mathrm{Szp}}/3\) 没有从其式子推出。更重要的是，(6.2) 先得到 \(c\) 的固定幂界；若要回到 \(h_F\) 的上界，还须使用 (5.2)–(5.5)，不能只凭 Faltings 高度的**下**界声称“等价”。

## 7. Step 5：所谓“显式阻碍族”论证不成立

### 7.1 标准 \(abc\) 失败不等于 \(q_n\to\infty\)

标准 \(abc\) 在某个固定 \(\varepsilon>0\) 处失败，意味着可以找到序列使

\[
\frac{c_n}{R_n^{1+\varepsilon}}\to\infty.
\]

但

\[
q_n=\frac{\log c_n}{\log R_n}
=1+\varepsilon+
\frac{\log(c_n/R_n^{1+\varepsilon})}{\log R_n}
\]

并不必趋于无穷；最后一项完全可能有界甚至趋于 0。\(q_n\to\infty\) 描述的是更弱的“有界质量”命题失败，逻辑上远强于标准 \(abc\) 在某个 \(\varepsilon\) 处失败。

### 7.2 从单向界不能得到稿件声称的极限

正确的无条件关系是

\[
\frac{\log|\Delta_{\min}(E_n)|}{\log N_{E_n}}
\ge
\frac{2\log c_n-O(1)}{\log R_n+7\log2}.
\tag{7.1}
\]

若真有 \(q_n\to\infty\)，(7.1) 才会推出 Szpiro 比无界。这会直接反驳固定幂弱 Szpiro／弱 \(abc\)，目前没有这样的显式族。

若只知道某个固定 \(\varepsilon\) 处的标准 \(abc\) 失败，(7.1) 至多给一个下界，不能把它改写成送审稿中的极限等式。其所谓“额外因子 6”也不是统一恒等式：

\[
c\le abc<c^3
\]

只给

\[
2\log c+O(1)
\le\log|\Delta_{\min}|
\le6\log c+O(1).
\]

系数取决于 \(a,b\) 相对 \(c\) 的大小，没有自动出现的固定因子 6。

因此 Step 5 没有提供 obstruction certificate；它只是把一个未知反例族写成条件句，并在条件句内部又发生了量词和极限错误。

## 8. 数值锚点 \((1,8,9)\) 的独立复核

精确整数结果为

\[
R=6,\quad
c_4=1168,\quad
\Delta_W=82944=2^{10}3^4,\quad
j=\frac{1556068}{81}.
\]

该模型已最小：在 2 处若还能以 \(u=2\) 缩放，判别式赋值必须至少减 12，但 \(v_2(\Delta)=10\)；在 3 处 \(c_4\equiv1\pmod3\)，为乘法约化。因此 \(\Delta_{\min}=82944\)。

| \(\log c\) | \(2.1972245773362196\) |
| \(q=\log c/\log R\) | \(1.226294385530917\) |
| \(\log|\Delta_{\min}|\) | \(11.325920960271892\) |
| \(\frac1{12}\log|\Delta_{\min}|\) | \(0.9438267466893243\) |
| \(1.5\log R\) | \(2.6876392038420827\) |

附件把 \(0.9438267\ldots\) 称为 \(h_F\) 的“估计”，但它只是非阿基米德有限项。取基本域中的

\[
\tau=1.5634019226961111\,i
\]

并计算 \(\Delta(\tau)=q\prod_{n\ge1}(1-q^n)^{24}\)，得到

\[
\log\bigl(|\Delta(\tau)|(\operatorname{Im}\tau)^6\bigr)
=-7.143259487041638.
\]

于是：

* 在 Murty–Pasten 的 (3.1) 归一化下，

  \[
  h_F(E_{1,8,9})\approx3.3769754370188063;
  \]

* 在 Löbrich Definition 2.3 所用的 Deligne 归一化下，

  \[
  h_F(E_{1,8,9})\approx0.2735862471248156.
  \]

两者相差固定归一化常数，并不矛盾。原“sanity check”有两个独立缺陷：它没有固定高度归一化，又无理由地把未知的 \(C_{0.5}\) 取成 1。在 Murty–Pasten 归一化和 \(C_{0.5}=1\) 下，\(3.3769>2.6876\)，原稿的勾号反而不成立；但这对允许任意 \(C_{0.5}\) 的 Claim 本身没有反证意义。

## 10. 可复现计算胶囊

下列仅用 Python 标准库的脚本复核所有承重整数结果、两个紧性例子及数值锚点；阿基米德乘积截断到双精度阈值，仅用于 sanity check，不参与 Steps 1–3 的证明。

~~~python
from fractions import Fraction
import math

def inv(a, b):
    c = a + b
    c4 = 16 * (a*a + a*b + b*b)
    D = 16 * (a*b*c)**2
    return c, c4, D, Fraction(c4**3, D)

def disc(a1, a2, a3, a4, a6):
    b2 = a1*a1 + 4*a2
    b4 = 2*a4 + a1*a3
    b6 = a3*a3 + 4*a6
    b8 = a1*a1*a6 + 4*a2*a6 - a1*a3*a4 + a2*a3*a3 - a4*a4
    return -b2*b2*b8 - 8*b4**3 - 27*b6*b6 + 9*b2*b4*b6

assert inv(1, 1)[2] == 64
assert disc(1, -4, 0, -1, 0) == 17**2

c, c4, D, j = inv(1, 8)
R = 6
assert (c, c4, D, j) == (9, 1168, 82944, Fraction(1556068, 81))

def agm(x, y):
    for _ in range(100):
        if abs(x-y) <= 1e-15 * max(abs(x), abs(y)):
            break
        x, y = (x+y)/2, math.sqrt(x*y)
    return (x+y)/2

def K(m):
    return math.pi / (2*agm(1.0, math.sqrt(1.0-m)))

m = 8/9
y = K(m)/K(1-m)
q = math.exp(-2*math.pi*y)
prod = 1.0
n = 1
while q**n > 1e-16:
    prod *= (1-q**n)**24
    n += 1
arch = math.log(q*prod*y**6)
h_mp = (math.log(D)-arch+12*math.log(2*math.pi))/12
h_del = math.log(D)/12-(arch+12*math.log(2*math.pi))/12+0.5*math.log(math.pi)

print(math.log(R), math.log(c)/math.log(R), math.log(D)/12)
print(y, arch, h_mp, h_del)
~~~

## 11. 最终裁决与可接受的修订命题

### 最终标签

\[
\boxed{\textbf{PARTIAL}}
\]

理由是：Steps 1–3 已在本文无条件完整证明；Step 4 所需固定幂弱 Szpiro／弱 \(abc\) 仍开放；Step 5 未提供显式反例族且其逻辑不成立。

### 可直接替换进原稿的无条件定理

对所有互素正整数 \(a+b=c\)，令 \(R=\operatorname{rad}(abc)\)。则

\[
|\Delta_{\min}(E_{a,b,c})|
\in\{16(abc)^2,\,2^{-8}(abc)^2\},
\]

\[
h_F(E_{a,b,c})\ge\frac16\log c-C
\]

（任一固定标准归一化下的绝对常数 \(C\)），且

\[
N_E=2^{f_2-1}R,\qquad0\le f_2\le8.
\]

### 开放问题的正确表述

是否存在一个可计算绝对常数 \(K>0\)，使所有上述三元组都满足

\[
h_F(E_{a,b,c})\le K\log R?
\]

这与该 Frey 族的有效固定幂弱 \(abc\)（全局有界质量）等价。它不是标准 \(abc\) 的 \(1+\varepsilon\) 形式，但截至文献截止日仍未解决。

若原作者真正想表达标准 \(abc\) 强度，就必须把待证式改为带有**固定领先系数**的形式，例如

\[
h_F(E_{a,b,c})\le\left(\frac16+\varepsilon\right)\log R+C_\varepsilon
\]

或另一条经过精确高度换算后与 \(c\le K_\varepsilon R^{1+\varepsilon}\) 对应的式子；不能把任意的 \(C_\varepsilon\) 乘在 \(1+\varepsilon\) 前面再声称指数仍为 \(1+\varepsilon\)。
