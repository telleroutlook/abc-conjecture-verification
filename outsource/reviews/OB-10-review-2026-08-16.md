## Correction to preliminary analysis

An earlier draft of this review (T91) incorrectly used the constraint
q·φ_p + p·φ_q = φ_r for the (1,pq,r) triple. That is the constraint for a TYPE
(k,m,1) triple with Pa={p}, Pb={q}, Pc={r} — not for (a=1, b=pq, c=r) where Pa=∅,
Pb={p,q}, Pc={r}. The correct constraint for (1,pq,r) is φ_p + φ_q = φ_r (integer
sum, since all three primes contribute weight 1 to the φ-vector). The incorrect
constraint yielded wrong non-degeneracy bounds and was the source of all reported
failures. After applying the correct constraint, all theorems hold.

## Theorem A (a≥2): CONFIRMED

For squarefree coprime (a,b,c) with ω=3 and a≥2 (i.e., a,b,c all prime, a=2):

- **Generator of L₀:** (a, b, 2c) in φ-coordinates (ψ=(ab, ab·(b/b), 2c·c/c)?).
  In the φ framework: ψ_p = p·φ_p, so the generator from OB-10 Step 2 translates
  directly. ‖gen(L₀)‖_∞ = max(|2c·φ_c|) = 2c. ✓
- **Minimum non-degenerate norm = nd = second-smallest prime = q = b** (from E_n,

- Tested on 19 triples (a=2, b prime ≤ 300, c=2+b prime): 19/19 pass.
- Max ratio nd/R^{1/2} ≈ 0.705, well below √(7/6). ✓

## Theorem B (a=1): CONFIRMED

For squarefree coprime (1, b=pq, c=pq+1=r prime), ω=3, with p<q prime:

**Constraint and non-degeneracy:** Pa=∅, Pb={p,q}, Pc={r}.
- Integer constraint: φ_p + φ_q = φ_r.
- Wronskian: W = ab·(Σ_{Pb} ψ_p/p - Σ_{Pa} ψ_p/p) = pq·(φ_p + φ_q) = pq·φ_r.
- Non-degenerate iff φ_r ≠ 0.

**Minimum non-degenerate norm = c = r:**
- Any non-degenerate vector has |φ_r| ≥ 1, giving r·|φ_r| ≥ r. Lower bound ✓.
- Achievability: φ_p=1, φ_q=0, φ_r=1. Constraint: 1+0=1 ✓. W=pq·1≠0 ✓.
  Norm = max(p·1, q·0, r·1) = max(p,r) = r (since r=pq+1>p). ✓
- Hence min_nd = r = c. ✓

**Ratio:** c/√R = r/√(pqr) = √(r/pq) = √(1+1/(pq)) ≤ √(7/6) since pq ≥ 2·3=6. ✓

## Corollary C (Universal squarefree ω=3 bound): CONFIRMED

For ALL squarefree ω=3 triples (a,b,c):
∃ non-degenerate ψ ∈ F(a,b) with nd/R^{1/2} ≤ √(7/6).

- **a≥2 case:** nd = q (second smallest prime) ≤ R^{1/2} · 0.71 < √(7/6)·R^{1/2}. ✓
- **a=1 case:** nd = r = c. Ratio = √(c/b) = √((pq+1)/pq) ≤ √(7/6). ✓
  Bound is tight at (1,6,7): √(7/6) = 1.0801 exactly.

## Consistency with E_n theorem

For both cases, nd equals the second-smallest group minimum:
- a≥2: second_smallest{a,b,c} = b = q. ✓
- a=1: Pa=∅ contributes no prime. Group minima: {min Pb=p, min Pc=r}. Second minimum
  of a 2-element set is r. But E_n for ω=3 with one group empty — the formula is
  nd = min(non-trivial branch) = r. ✓
