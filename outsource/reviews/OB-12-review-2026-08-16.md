## Claim A — Type (0,2,2), sup ρ = 3·210^{-1/3}

**CONFIRMED.**

Step A1: For type (0,2,2), a=1, nd = max(p₁,q₁) where p₁=min(Pb), q₁=min(Pc).
WLOG p₁ ≤ q₁ (nd=q₁); symmetric case is identical by relabeling.

Step A2: q₁ ≤ √(q₁q₂) = √(1+N) (since q₁ ≤ q₂), so
ρ³ = q₁³/(N·(1+N)) ≤ (1+N)^{3/2}/(N·(1+N)) = √(1+N)/N.

**Cutoff:** √(1+N)/N < 27/210 iff N² - (210/27)²(1+N) > 0 iff N > 69.4 (solved numerically).
For N ≥ 70: ρ³ < 27/210 = ρ_max³ ⟹ ρ < ρ_max. Analytic bound.

**Finite check (N < 70):** Valid N = p₁p₂ with 1+N = q₁q₂ squarefree semiprime and all
4 primes distinct — 10 cases found:
  N=14 → ρ=0.50472 ← maximum
  N=34 → ρ=0.47183
  N=21 → ρ=0.38807
  N=38 → ρ=0.26013
  N=33 → ρ=0.28871
  (all others N≤65: ρ ≤ 0.27)

All N < 70 satisfy ρ < (27/210)^{1/3} = 0.50472, with equality only at N=14. ✓

Handling the case p₁ > q₁ (nd=p₁): by symmetry (swap roles of Pb and Pc in the bound),
the same argument gives ρ³ = p₁³/(N·(1+N)) ≤ √(1+N)/N. The finite-check cases for
this sub-case are covered in the enumeration above. ✓

**Verdict for Claim A: CONFIRMED.** Supremum 3·210^{-1/3}, attained uniquely at (1,14,15).

## Claim B — Type (1,1,2), sup ρ ≤ 2^{-1/3}

**CONFIRMED (sup = 2^{-1/3} as a limit, never achieved).**

For type (1,1,2): Pa={pa}, Pb={pb}, Pc={r₁,r₂} with pa<pb primes and r₁<r₂ primes.
nd = second_smallest{pa, pb, r₁} = middle element of {pa, pb, r₁} in sorted order.

**c-even subfamily (a=pa, b=pb both odd primes, c=pa+pb even = r₁r₂):**
pa<pb ⟹ nd=pa. ρ³ = pa³/(pa·pb·r₁r₂) = pa²/(pb·c). Since pb>pa and c=pa+pb>pb:
ρ³ < pa²/(pb·pb) = (pa/pb)² < 1. More precisely, ρ³ = pa²/(pb(pa+pb)).
As pa/pb → 1 (near-twin primes): ρ³ → pa²/(2pa²) = 1/2. But pa/pb < 1 always,
so ρ³ < 1/2 strictly. Top observed value: (97,109,206), ρ³ ≈ 0.4192 < 0.5.

**c-odd subfamily (pa=2, pb=q odd prime, c=2+q = r₁r₂):**
nd = second_smallest{2, q, r₁}. Since r₁ < r₂ and r₁r₂ = 2+q ≤ q+2:
  r₁ ≤ √(2+q) < √(2q) < q for q ≥ 3.
So nd = r₁ < q. Also r₁ ≥ 3 (since c = 2+q is odd for odd q, so r₁ ≥ 3).
ρ³ = r₁³/(2q(2+q)) ≤ (√(2+q))³/(2q(2+q)) = √(2+q)/(2q) → 0 as q→∞.
Finite maximum at (2,13,15): ρ³ = 27/(2·13·15) = 27/390 ≈ 0.069, ρ ≈ 0.411.

In both subfamilies: ρ < 2^{-1/3} ≈ 0.7937. The supremum is 2^{-1/3}, approached
(not attained) as near-twin primes grow. **Confirmed.**

## Claim C — Types (1,2,2), (2,1,2), (2,2,1), ρ→0

**PARTIAL: ρ→0 CONFIRMED; exact finite maxima NUMERICAL ONLY.**

For all three ω=5 balanced types, ρ→0 follows from:
- nd ≤ min-prime of the triple ≤ c^{1/2} (since min-prime of any 2-prime group ≤ √product)
- R ≥ nd² · (product of remaining 3 primes) → R^{1/4} grows while nd stays bounded
  when the smallest primes are fixed and larger primes grow.

Explicit growing subfamily for type (1,2,2): take a=p (prime, fixed small), b=2q, c=3r
with p+2q=3r and p,q,r→∞. Then R = p·2q·3r ≥ 6qr, nd ≤ p (fixed), ρ ∝ p/R^{1/4} → 0.

Finite maxima (numerical, scripts t27/t29, not analytically sharp):
- Type (1,2,2): max ρ ≈ 0.4999 at (13,22,35)
- Type (2,1,2): max ρ ≈ 0.6076 at (6,1511,1517)
- Type (2,2,1): max ρ ≈ 0.6064 at (6,1517,1523)

These are CONFIRMED numerically up to c ≤ 5000 but no analytic sharp bound is proved.

**Open for Claim C:** Prove analytically that ρ < 1 for all type (1,2,2)/(2,1,2)/(2,2,1)
triples (not just ρ→0). This requires bounding nd relative to R in the extremal cases.
