## Step 1 ERROR: Minimum norm is NOT r

OB-11 Step 1 claims: "minimum norm = r, achieved by v₁=(p,0,r) and v₂=(0,q,r)."

**This is wrong.** The vector v₃ = (p, −q, 0) is in L:

    q·r·p + p·r·(−q) − p·q·0 = pqr − pqr − 0 = 0  ✓

and has ‖v₃‖_∞ = max(p, q) = q (assuming p < q), which satisfies q < r = p+q.

OB-11's Step 1 argument ("any solution has s≥1, so ψ_r = rs ≥ r") ignores the
case ψ_r = 0, where the lattice constraint gives q·ψ_p + p·ψ_q = 0 and
non-trivial solutions (p,−q,0) exist with norm q < r.

**Brute-force verification** (T44, all ω=3 twin-prime triples with p,q≤200,
15 triples total): min norm = q in every case, never = r. OB-11 Step 1 wrong
for all 15 triples.

## Corrected proof

**Correct minimum norm = q = second_smallest{p,q,r}**, consistent with F10.

### Step 1 (corrected): Min norm = q

Case ψ_r = 0: Constraint reduces to q·ψ_p + p·ψ_q = 0. Since gcd(p,q) = 1
(distinct primes), p | ψ_p. Write ψ_p = p·t, ψ_q = −q·t. For nonzero ψ,
|t| ≥ 1, so ‖ψ‖_∞ = max(p,q)·|t| ≥ q. Equality at t = 1: v₃ = (p,−q,0).

Case ψ_r ≠ 0: Since gcd(r, pq) = 1 (r = p+q, all three distinct primes),
r | ψ_r. So |ψ_r| ≥ r > q, giving ‖ψ‖_∞ ≥ r > q.

Therefore min norm = q, achieved by v₃ = (p,−q,0).

### Step 2 (corrected): v₃ is non-degenerate

    W(v₃) = (p·(−q) − q·p) = −2pq ≠ 0.  ✓

### Step 3: Min norm < degenerate min norm

    ‖v₃‖_∞ = q  <  2q ≤ 2r = ‖v₀‖_∞  (degenerate minimum).

Actually: the degenerate minimum is 2r (from OB-11 Step 3, unchanged), and
q < r < 2r, so the minimum-norm vector (v₃, norm=q) is strictly non-degenerate
before any degenerate vector appears (norm ≥ 2r).
